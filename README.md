# Preemption-bounded Consistency Testing

Course presentation for **CS 766 - Analysis of Concurrent Programs**, IIT Bombay (CSE).

**Presenter:** Malay Kedia  
**Date:** March 2025

Slides summarizing hardness and tractability results for *consistency testing* when the number of preemptions in a concurrent run is bounded.

## Primary paper

R. Govind, S. Krishna, Sanchari Sil, B. Srivathsan — *Verifying Sequential Consistency under Bounded Preemptions*.
